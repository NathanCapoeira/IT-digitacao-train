IT Digitação Legacy 2.0.0-beta.3 — distribuição de desenvolvimento

A edição usa WPF programático, .NET Framework 3.5, CLR 2.0 e Release x86. Requer que o .NET Framework 3.5 já esteja habilitado no Windows. Funciona offline após extrair a pasta completa; não exige instalação do aplicativo nem privilégios de administrador.

O Core, catálogo, preferências, aplicativo, criador de atalhos e empacotamento são compilados/validados pelo workflow do GitHub Actions. Consulte o log do workflow associado ao commit para saber o resultado desta compilação específica.

A interface e as funcionalidades principais foram migradas com base nos XAML e code-behind da Standard. Esta compilação ainda não satisfaz o critério de equivalência integral para RC:
- O layout é recriado por controles programáticos e não foi comparado por capturas de tela nas resoluções da Standard.
- O editor ainda não acompanha automaticamente o trecho visível de referência; os tamanhos e alturas podem diferir da Standard.
- O teclado ABNT2 e o mapeamento das teclas/dedos precisam de conferência no equipamento-alvo.
- Resultados, conquistas, perguntas, configurações e retomada foram implementados, mas seus fluxos visuais e interação precisam de validação no WPF 3.5.
- A versão desta entrega não foi testada presencialmente no Windows 7 SP1.
- A execução de Criar-Atalho.exe, inclusive o aviso para unidade removível, deve ser confirmada nos computadores do instituto.

Não trate a Beta como compatibilidade definitiva, equivalência completa ou RC. Preserve a pasta extraída inteira. Para criar o atalho do usuário atual, execute Criar-Atalho.exe a partir da pasta do aplicativo.
