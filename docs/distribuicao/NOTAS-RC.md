## IT Digitação 2.0.0-rc.1

Versão candidata para o piloto do Instituto de Transformação. Inclui biblioteca offline com 50 textos em dez categorias, editor, sessões de 5 a 30 minutos, métricas, resumo, guia ABNT2 e preferências locais.

1. Confira o SHA-256 do ZIP em `SHA256SUMS.txt`.
2. Extraia todos os arquivos para uma pasta local.
3. Abra `IT-Digitacao.exe`. O aplicativo requer .NET Framework 4.8 ou atualização compatível.

O pacote é x86. Os testes de CI usam Windows Server 2022 x64. Windows 7 SP1, Windows 10 e Windows 11 aguardam validação presencial. Também estão pendentes a revisão factual dos textos, o piloto pedagógico e a avaliação de teclado físico e DPI nas máquinas do Instituto.

O pacote portátil está anexado junto com as evidências técnicas. [Instruções de instalação](https://github.com/NathanCapoeira/IT-digitacao-train/blob/v2.0.0-rc.1/docs/INSTALACAO.md)
